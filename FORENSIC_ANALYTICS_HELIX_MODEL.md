## [HELIX] 2. Architectural Pillars

### Left Pillar: The Digital World
- **Domain Focus**: Non-volatile media, packet flows, memory artifacts, signal logs, metadata telemetry.
- **Core Language**: Logical state transitions, network graphs, timestamp correlations, digital footprints.

### Right Pillar: The Physical World
- **Domain Focus**: Wet-lab analysis, physical biometrics, hardware trace materials, sensor arrays, environmental telemetry.
- **Core Language**: Empirical measurements, material spectroscopy, spatial telemetry, physical state transitions.
